# Portfolio de Jose Cabrera Martín

Portfolio profesional en español, publicado como sitio estático en GitHub Pages.

## Vista local

No necesita instalación ni proceso de compilación. Se puede abrir `index.html` directamente o servir la carpeta con cualquier servidor HTTP local, por ejemplo:

```powershell
python -m http.server 8000
```

Después, abre `http://localhost:8000`.

## Edición

- El contenido y la estructura están en `index.html`.
- Los estilos y puntos de adaptación responsive están en `styles.css`.
- La navegación móvil, el estado de sección y las transiciones están en `script.js`.

## Publicación

El repositorio está preparado para GitHub Pages desde la rama `main`. Al tratarse del repositorio de usuario `jCabreraMartin.github.io`, la URL pública es:

https://jCabreraMartin.github.io/

No incluye analítica, scripts de terceros ni formularios con backend.
